## Sobre el par 08 / 09 — es el argumento central

Son la misma prenda con **el largo cambiado y nada más**. Comparándolas se ve lo
que ningún programa de dibujo hace: la remera se alargó y **el ancho de pecho, el
cuello y las mangas quedaron idénticos** (60 / 18 / 18 cm en las dos).

En un programa de dibujo, estirarla para alargarla la habría ensanchado igual.

Si la landing muestra una sola cosa, que sea esto. Ideas: las dos imágenes lado a
lado con una línea que marque el ancho igual, o una animación entre ambas.

## Antes de publicarlas

Son PNG grandes (1254 px de ancho, pantalla completa). Conviene:

- **Recortar** el panel del navegador y quedarse con lo que importa.
- Pasarlas a **WebP** o comprimirlas: así como están pesan de más para una landing.
- Para el par 08/09, **recortar las dos igual** para que la comparación sea justa.
