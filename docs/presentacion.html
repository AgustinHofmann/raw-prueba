Stack tecnológico

Herramientas que usamos y por qué

Vite

Bundler y Dev Server

Es la herramienta que sirve el código al navegador mientras desarrollamos y que lo empaqueta para producción.

¿Por qué Vite? Cuando cambiás un archivo, el navegador actualiza solo ese módulo en menos de un segundo, sin recargar la página. Esto es crítico cuando ajustás una herramienta del editor y no querés perder lo que tenías dibujado.

Hot reload instantáneo npm run dev npm run build
React 19

Interfaz de Usuario

Librería para construir la UI mediante componentes reutilizables.

¿Por qué React? Cuando cambia la herramienta activa o el color del trazo, React actualiza automáticamente solo los componentes que lo necesitan. Sin React tendríamos que actualizar el DOM a mano en cada acción.

Componentes useState useEffect useRef
TypeScript

JavaScript con Tipos

Agrega un sistema de tipos estáticos sobre JavaScript.

¿Por qué TypeScript? El editor tiene muchos tipos de objetos y estados distintos. Con TypeScript el editor te avisa si te equivocás de tipo antes de correr el código. También da autocompletado completo de la API de Fabric.js, que es enorme.

Errores en tiempo de edición Autocompletado Tipos personalizados
Fabric.js 6

Motor del Canvas

Librería que convierte el Canvas HTML5 (que solo dibuja píxeles) en un sistema de objetos: cada trazo es un objeto que se puede seleccionar, mover, editar y borrar.

¿Por qué Fabric? Sin él, tendríamos que manejar a mano toda la lógica de selección, transformación y renderizado de objetos. Fabric nos da todo eso ya resuelto.

Objetos editables Eventos de mouse Transformaciones Serialización JSON
SVG / Curvas Bezier

El Lenguaje de los Trazos

Los trazos se guardan como paths SVG: texto que describe curvas matemáticamente.

¿Por qué SVG? A diferencia de los píxeles, los paths SVG se pueden escalar infinitamente sin perder calidad, editar punto a punto, y reconstruir parcialmente (lo que permite la goma de borrar por radio).

Curvas cúbicas Escalado infinito Catmull-Rom Bezier
localStorage

Persistencia de Datos

Almacenamiento del navegador que guarda datos entre sesiones sin necesitar un servidor.

¿Cómo lo usamos? Al guardar, el canvas se serializa a JSON y se guarda junto con una miniatura. Al abrir la app, se restaura automáticamente el estado exacto del proyecto.

Sin servidor Miniatura automática JSON del canvas
